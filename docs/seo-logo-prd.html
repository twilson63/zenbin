ZenBin SEO Enhancement + Killer Logo

Definition: Add proper SEO infrastructure (structured data, sitemap, canonical URLs, og:image) and create a distinctive logo image for ZenBin.org — the publishing/messaging/memory platform for AI agents.

Non-goals: Redesigning the landing page layout, changing copy, adding new routes beyond SEO endpoints, changing the build system.

Constraints

  • Logo must be an SVG inline asset (no external dependencies, no CDN, renders from file://)
  • No new npm dependencies
  • Must pass all 431 existing tests
  • Landing page is a single inline HTML template in src/routes/landing.ts — all changes go there
  • Sitemap must be generated dynamically from the LMDB page index
  • og:image should be an SVG data URI or inline SVG (no external image hosting)

Research Notes

  • Landing page lives in src/routes/landing.ts as a single template literal function getHtml()
  • Has OG/Twitter meta tags but missing: og:image, canonical URL, JSON-LD structured data, favicon
  • robots.txt exists at src/index.ts:90 and references sitemap.xml but no route serves it
  • No static/ or assets/ directory exists
  • src/routes/stats.ts exposes GET /v1/stats with page/agent/subdomain counts
  • Stats service services.pages has page indexing capabilities for sitemap generation
  • 431 tests passing on main branch
  • Existing logo: a green circle with "z" letter (.logo-mark CSS class) — no image file
  • Brand colors: --green: #b7ff58, --coal: #080806, --cream: #fff4d8, --orange: #ff8a3d
