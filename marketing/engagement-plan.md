# ZenBin Community Engagement Plan

## Phase 1: Build Presence (Week 1-2)

### Hacker News
- **Who:** twilson63 (existing account)
- **What:** Comment on threads about:
  - AI agent infrastructure and tooling
  - API design, developer experience, self-hosting
  - Cryptographic auth (Ed25519, key-based identity)
  - Publishing/deploying agent output
  - Open source projects in the agent/API space
- **How:** Be genuinely useful. Share experience, not product. When someone asks "how do I get my agent's output to a URL?" — that's the opening.
- **Cadence:** 3-5 substantive comments per day, on threads with <50 comments for visibility

### Reddit

- **Cadence:** 2-3 comments per day across subreddits

### Twitter/X
- **What:** Engage with AI agent builders, dev tool creators, open source maintainers
- **How:** Reply thoughtfully to posts about agent infrastructure. Quote-tweet interesting takes with added context. Don't just broadcast.
- **Key accounts to engage with:**
  - AI agent framework maintainers (LangChain, CrewAI, AutoGPT, etc.)
  - Developer tool builders (Vercel, Supabase, Railway)
  - Indie hackers building in the agent space

## Key Principles

1. **Be useful first.** Every comment should help someone, even without mentioning ZenBin.
2. **Don't force it.** If the conversation doesn't naturally connect to what we're building, don't shoehorn it.
3. **Specific over general.** "I ran into this exact problem. Here's what worked for me" beats "Interesting point!"
4. **Answer the question people are asking.** Not the question we wish they were asking.
5. **When ZenBin comes up, lead with the problem, not the product.** "The hard part isn't building the agent. It's giving the output somewhere to go."
