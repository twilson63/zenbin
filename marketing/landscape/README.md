# Agent Landscape Research

Research on the competitive landscape for ZenBin — who's building what, where the gaps are, and how we position.

## Files

- **competitors.md** — Direct and adjacent competitors, comparison table
- **standards.md** — Agent identity/auth standards (IETF, FIDO, NIST, CoSAI, AI Agent Passport)
- **infrastructure.md** — Agent deployment, runtime, MCP ecosystem
- **trends.md** — Key trends, HN discussions, market signals
- **updates.md** — Chronological update log from automated research

## Key Takeaway

**No direct competitors found.** The agent output publishing gap remains completely unfilled. Every new project addresses input, execution, identity, or commerce — no one is solving "where does agent output go?"

ZenBin owns this space.
